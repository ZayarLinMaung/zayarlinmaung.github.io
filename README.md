# zayarlinmaung.github.io

Game Boy–themed portfolio for **Zayar Lin Maung** (DevOps Engineer).

## Local

```bash
export PATH="$HOME/.local/node/bin:$PATH"
npm install
npm run dev
```

## GitHub Pages

Built with Vite. The site is the **`dist/`** output (not the React source).

1. Repo **Settings → Pages → Build and deployment**
2. Set **Source** to **GitHub Actions**  
   (or **Deploy from a branch** → `gh-pages` / `/` if using the branch workflow)
3. Push to `main` — the workflow builds and publishes automatically

Live site: https://zayarlinmaung.github.io
